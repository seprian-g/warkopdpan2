# Warkop D'PAN — Landing Page

Landing page satu file (`index.html`), siap dibuka langsung di browser atau di-hosting statis (GitHub Pages, Netlify, dll).

- `index.html` — hasil akhir (semua gambar & video sudah tertanam).
- `src/` — sumber (`src.html`, `build.py`, video & poster hero) untuk mengedit lalu build ulang.

Edit `CONFIG` di bagian script: nomor WhatsApp, link Maps, alamat, Instagram, TikTok, dan `tiktokVideos` (ID video TikTok untuk tampil 3 video 9:16).
